# Pedro Tiago — Sites e experiências digitais

[Visite o portfólio publicado](https://pedro-tiago-sites.sabedoriameditativa.chatgpt.site)

Portfólio de sites e jogos de navegador, desenvolvido por Pedro Tiago com apoio de IA. As cafeterias são marcas fictícias, usadas para demonstrar possibilidades de criação.

## Projetos de destaque

| Projeto | Objetivo | Demonstração e código |
| --- | --- | --- |
| Café Aurora | Apresentar uma cafeteria e organizar um cardápio com pedido de exemplo | [Demo publicada](https://pedro-tiago-sites.sabedoriameditativa.chatgpt.site/demo/) · [Código](demo/index.html) |
| Casa Âmbar | Explorar uma identidade visual própria, filtros de cardápio e reserva simulada | [Demo publicada](https://pedro-tiago-sites.sabedoriameditativa.chatgpt.site/demo/casa-ambar/) · [Código](demo/casa-ambar/index.html) |
| Corrida Neon | Demonstrar animação e interação por teclado e controles para celular | [Jogar](https://pedro-tiago-sites.sabedoriameditativa.chatgpt.site/projetos/corrida-neon/) · [Código](projetos/corrida-neon/index.html) |

Pedidos e reservas são simulações. Não são apresentados como projetos contratados por clientes nem como resultados comerciais medidos.

## Executar localmente

Com Python 3 instalado, na pasta deste repositório execute:

```sh
python3 -m http.server 8000
```

Abra `http://localhost:8000`. Não há instalação de dependências, backend de reservas ou pagamento nestas demonstrações.
